# 📋 Auftragsbearbeitung: Sprachnachricht bis Fertigung

## Phase 1: Eingang & Prüfung
- [ ] Sprachnachricht empfangen und anhören
- [ ] Nachricht auf verwertbare Informationen prüfen (z. B. gesuchtes Objekt: *Schraubendreherhalter*)
- [ ] Kundendetails und spezielle Wünsche notieren

## Phase 2: Recherche & Auswahl
- [ ] Internet-Suche nach passenden STL-Dateien starten (z. B. STL-Modelle für das gesuchte Objekt)
- [ ] Eine Auswahl von Beispielen sichten (z. B. 3 verschiedene Modelle)
- [ ] Passende STL-Beispiele für den Kunden auswählen und speichern

## Phase 3: Datenanalyse & Angebotserbereitung
- [x] **Technische Daten aus STL-Datei ermitteln:**
    - [x] Maße des Werkstücks bestimmen
    - [x] Dauer der Fertigung kalkulieren
    - [x] Materialverbrauch ermitteln
    - [x] Abbildung/Vorschau des Modells sichern
    - [x] GCODE-Daten für die Fertigung erstellen/generieren
- [x] **Angebot erstellen:**
    - [x] Angebotsdaten in einem Dokument zusammenfassen
    - [x] Sprachnachricht oder Textnachricht für den Kunden vorbereiten
    - [ ] Daten zur Nachbearbeitung im zentralen Datensystem speichern

## Phase 4: Freigabe
- [ ] Angebot an den Kunden übermitteln
- [ ] Auf Auftragserteilung / Freigabe warten

## Phase 5: Produktion
- [ ] Maschine mit den Fertigungsdaten (GCODE) bestücken
- [ ] Materialvorrat und Druckbett prüfen
- [ ] Werkstück drucken / fertigen
- [ ] Qualitätsprüfung durchführen und Auftrag abschließen
